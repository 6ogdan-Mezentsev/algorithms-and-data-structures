Студент ИТМО, Мезенцев Богдан Геннадьевич | 466683

## Задание 
Можно найти максимальный подмассив за линейное время, воспользовавшись следующими идеями.
Начните с левого конца массива и двигайтесь вправо, отслеживая найденный к данному моменту максимальный подмассив.
Зная максимальный подмассив массива А[1..j), распространите ответ на поиск максимального подмассива, заканчивающегося индексом j + 1, воспользовавшись следующим наблюдением: максимальный подмассив массива А[1..j + 1] представляет собой либо максимальный подмассив массива А[1..j], либо подмассив A[i..j + 1] для некоторого 1 ≤ i ≤ j + 1.
Определите максимальный подмассив вида A[i..j + 1] за константное время, зная максимальный подмассив, заканчивающийся индексом j.
## Input / Output 

| Input     | Output |
|-----------|--------|
| 5         | 15     |
| 1 2 3 4 5 |        |
